Les mises à jour●Dot Box et tes apps, séparément, et seulement quand tu le décides.

Updates●Dot Box and your apps, separately, and only when you decide.

Mettre à jour Dot Box

$ dotbox upgrade

Remplace le binaire et relance l'interface et l'API. Les apps ne sont pas touchées. Si la nouvelle version change le format des manifests ou de dotbox.yml, upgrade convertit les fichiers et l'indique dans son résumé.

Mettre à jour une app

$ dotbox update radarr
$ dotbox update --all

Chaque manifest fixe une version d'image (lscr.io/linuxserver/radarr:5.26.2), jamais latest: ce qui tourne est toujours connu. update passe à la version la plus récente, recrée le container et attend qu'il soit Running avant de passer à l'app suivante. Une app qui ne redémarre pas arrête la série.

Revenir en arrière

$ dotbox update radarr --rollback

L'image précédente est gardée sur le serveur: --rollback la remet en place si la nouvelle version pose problème.

Voir ce qui est disponible

$ dotbox diff
  ~ radarr     5.26.2, 5.27.0 available
  ~ sonarr     4.0.15, 4.0.16 available

Mises à jour automatiques

Désactivées par défaut: une mise à jour se fait quand tu la lances. Pour les programmer, une section dans dotbox.yml, sans Watchtower:

update:
  schedule: sunday 05:00
  apps: [radarr, sonarr, prowlarr]   # ou all

Une sauvegarde de chaque app concernée est faite juste avant.

Update Dot Box

$ dotbox upgrade

Replaces the binary and restarts the interface and the API. Apps are not touched. If the new version changes the manifest or dotbox.yml format, upgrade converts the files and says so in its summary.

Update an app

$ dotbox update radarr
$ dotbox update --all

Each manifest pins an image version (lscr.io/linuxserver/radarr:5.26.2), never latest, so what runs is always known. update moves to the newest version, recreates the container and waits for it to be Running before moving to the next app. An app that fails to restart stops the run.

Roll back

$ dotbox update radarr --rollback

The previous image stays on the server: --rollback puts it back if the new version causes trouble.

See what is available

$ dotbox diff
  ~ radarr     5.26.2, 5.27.0 available
  ~ sonarr     4.0.15, 4.0.16 available

Automatic updates

Off by default: an update happens when you run it. To schedule them, one section in dotbox.yml, no Watchtower needed:

update:
  schedule: sunday 05:00
  apps: [radarr, sonarr, prowlarr]   # or all

Each app concerned is backed up just before.
