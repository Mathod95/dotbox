Serveur de test · install.sh puis core · aucune app

Tout ce que Claude fait sur le serveur de test (et sur ton PC pour y accéder), commande par commande: ce qu'elle fait, ce qu'elle change sur la machine, comment l'annuler. Les étapes « proposées » attendent ton accord, rien n'est lancé avant.

Règles. Aucune commande qui écrit sur le serveur sans ton accord explicite. Chaque commande lancée est ajoutée ici avec l'heure et son résultat, y compris les lectures. Rien de personnel sur cette page: l'IP, le domaine et les mots de passe sont masqués. Le serveur est désigné par son alias SSH dotbox-test.

Questions ouvertes

Ce qui ne sera pas fait

  • Aucune app: ni qBittorrent, Prowlarr, Radarr, Sonarr, ni serveur média. Seulement le core.
  • Ni dotbox init ni l'interface web Dot Box: aucun code n'existe encore (étape B).
  • Pas de sauvegarde programmée (elle dépend de dotbox backup).
  • Pas d'apt upgrade ni de full-upgrade, pas de redémarrage du serveur.
  • Aucune modification de la config SSH (/etc/ssh/).
