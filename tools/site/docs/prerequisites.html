Prerequisites●the server, domain and DNS Dot Box needs.

Le serveur

Dot Box n'a besoin que de Docker et d'un binaire. Il tourne uniquement sur un serveur dédié chez un hébergeur, avec un nom de domaine à toi: pas d'installation à la maison.

ÉlémentMinimumConseillé
Systèmeversions LTS uniquement: Debian 12 ou 13, Ubuntu 24.04 ou 26.04, installation neuveDebian 13
Processeuramd64, 2 cœurs4 cœurs, avec puce graphique pour le transcodage du serveur média
Mémoire2 Go pour le core (Traefik, Authelia, CrowdSec, Dot Box)8 Go avec beaucoup d'apps
Disque20 Go pour le système et /opt/data sur un disque à part, assez grand pour tes médias
Accèsroot ou sudo en SSHune clé SSH, sans mot de passe

Rien d'autre ne doit être installé. dotbox init installe Docker s'il est absent, et s'arrête si un autre reverse proxy occupe déjà les ports 80 et 443.

Réseau

  • Ports 80 et 443 ouverts depuis internet, pour Traefik: le 80 sert à obtenir les certificats et à rediriger vers HTTPS, le 443 aux apps.
  • Le port SSH (22 ou le tien), pour l'administration et l'accès de secours.

Le domaine

Chaque app est servie sur son sous-domaine (radarr.example.com), jamais par IP et port: les ports des containers restent sur le réseau interne dotbox. Il te faut donc un nom de domaine à toi.

Le DNS

Avant de lancer l'installation, crée un seul enregistrement chez ton fournisseur DNS: *.example.com vers l'IP du serveur. Tous les sous-domaines arrivent alors sur le serveur, et Traefik envoie chacun vers la bonne app.

NomTypeValeur
*.example.comAl'IPv4 du serveur, par exemple 203.0.113.10
*.example.comAAAAl'IPv6 du serveur, s'il en a une

Dot Box n'a besoin d'aucun accès à ton compte DNS: il ne crée ni ne modifie aucun enregistrement. dotbox init vérifie seulement que *.example.com pointe bien vers le serveur avant d'aller plus loin. Tes enregistrements existants (mail, www...) restent prioritaires sur le wildcard.

Les certificats

Traefik demande un certificat à Let's Encrypt (ou ZeroSSL, au choix dans dotbox.yml) pour chaque sous-domaine, dès que l'app est installée, par le challenge HTTP-01: Let's Encrypt vérifie que le sous-domaine répond sur le port 80 du serveur. Les certificats se renouvellent tout seuls.

Comme tout certificat, ils sont inscrits dans des registres publics: on peut y voir qu'un sous-domaine comme radarr.example.com existe, pas ce qu'il contient.

Optionnel

  • Un stockage hors du serveur pour les sauvegardes: un remote rclone, un NAS en SFTP ou un bucket S3.
  • Des sources pour Prowlarr: pas nécessaires pour installer, seulement pour télécharger.
  • Un compte Plex, seulement si tu installes Plex. Jellyfin n'a besoin d'aucun compte externe.

The server

Dot Box only needs Docker and one binary. It only runs on a dedicated server at a hosting provider, with a domain name of your own: no home install.

ItemMinimumRecommended
SystemLTS releases only: Debian 12 or 13, Ubuntu 24.04 or 26.04, fresh installDebian 13
CPUamd64, 2 cores4 cores, with a GPU for media server transcoding
Memory2 GB for the core (Traefik, Authelia, CrowdSec, Dot Box)8 GB with many apps
Disk20 GB for the system and /opt/data on a separate disk, large enough for your media
Accessroot or sudo over SSHan SSH key, no password

Nothing else should be installed. dotbox init installs Docker if it is missing, and stops if another reverse proxy already uses ports 80 and 443.

Network

  • Ports 80 and 443 open to the internet, for Traefik: 80 is used to get certificates and to redirect to HTTPS, 443 serves the apps.
  • The SSH port (22 or yours), for administration and emergency access.

The domain

Each app is served on its own subdomain (radarr.example.com), never by IP and port: container ports stay on the internal dotbox network. So you need a domain name of your own.

DNS

Before running the install, create a single record at your DNS provider: *.example.com pointing to the server's IP. Every subdomain then reaches the server, and Traefik sends each one to the right app.

NameTypeValue
*.example.comAthe server's IPv4, for example 203.0.113.10
*.example.comAAAAthe server's IPv6, if it has one

Dot Box needs no access to your DNS account: it creates and changes no records. dotbox init only checks that *.example.com points to the server before going further. Your existing records (mail, www...) take priority over the wildcard.

Certificates

Traefik requests a certificate from Let's Encrypt (or ZeroSSL, set in dotbox.yml) for each subdomain, as soon as the app is installed, through the HTTP-01 challenge: Let's Encrypt checks that the subdomain answers on the server's port 80. Certificates renew on their own.

Like any certificate, they are listed in public logs: anyone can see that a subdomain such as radarr.example.com exists, not what it holds.

Optional

  • Off-server storage for backups: an rclone remote, a NAS over SFTP or an S3 bucket.
  • Sources for Prowlarr: not needed to install, only to download.
  • A Plex account, only if you install Plex. Jellyfin needs no outside account.
