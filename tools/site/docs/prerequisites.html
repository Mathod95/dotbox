Prerequisites●the server, domain and DNS Dot Box needs.

Le serveur

Dot Box n'a besoin que de Docker et d'un binaire. Il tourne uniquement sur un serveur dédié chez un hébergeur, avec un nom de domaine à toi: pas d'installation à la maison.

ÉlémentMinimumConseillé
SystèmeDebian 12 ou Ubuntu 24.04 LTS, installation neuveDebian 13
Processeuramd64 ou arm64, 2 cœurs4 cœurs, avec puce graphique pour le transcodage du serveur média
Mémoire2 Go pour le core (Traefik, Authelia, Dot Box)8 Go avec beaucoup d'apps
Disque20 Go pour le système et /opt/data sur un disque à part, assez grand pour tes médias
Accèsroot ou sudo en SSHune clé SSH, sans mot de passe

Rien d'autre ne doit être installé. dotbox init installe Docker s'il est absent, et s'arrête si un autre reverse proxy occupe déjà les ports 80 et 443.

Réseau

  • Ports 80 et 443 ouverts depuis internet, pour Traefik.
  • Le port SSH (22 ou le tien), pour l'administration et l'accès de secours.

Le domaine

Chaque app est servie sur son sous-domaine (radarr.mathod.fr), jamais par IP et port: les ports des containers restent sur le réseau interne dotbox. Il te faut donc un nom de domaine à toi.

Le DNS

Dot Box demande un certificat wildcard *.mathod.fr à Let's Encrypt (ou ZeroSSL, au choix dans dotbox.yml) par le challenge DNS-01. Il a besoin d'un jeton API de ton fournisseur DNS, limité à la zone du domaine.

FournisseurCe qu'il faut
Cloudflareun jeton API avec la permission « Zone DNS: Edit » sur la zone
OVHapplication key, application secret et consumer key
Scalewayune clé API
Gandiun jeton d'accès personnel
Autretout fournisseur pris en charge par Traefik, ou les enregistrements créés à la main

Avec un fournisseur pris en charge, Dot Box crée aussi les enregistrements A et AAAA du wildcard vers l'IP du serveur. Sinon, crée *.mathod.fr à la main avant de lancer dotbox init.

Optionnel

  • Un stockage hors du serveur pour les sauvegardes: un remote rclone, un NAS en SFTP ou un bucket S3.
  • Des sources pour Prowlarr: pas nécessaires pour installer, seulement pour télécharger.
  • Un compte Plex, seulement si tu installes Plex. Jellyfin n'a besoin d'aucun compte externe.

The server

Dot Box only needs Docker and one binary. It only runs on a dedicated server at a hosting provider, with a domain name of your own: no home install.

ItemMinimumRecommended
SystemDebian 12 or Ubuntu 24.04 LTS, fresh installDebian 13
CPUamd64 or arm64, 2 cores4 cores, with a GPU for media server transcoding
Memory2 GB for the core (Traefik, Authelia, Dot Box)8 GB with many apps
Disk20 GB for the system and /opt/data on a separate disk, large enough for your media
Accessroot or sudo over SSHan SSH key, no password

Nothing else should be installed. dotbox init installs Docker if it is missing, and stops if another reverse proxy already uses ports 80 and 443.

Network

  • Ports 80 and 443 open to the internet, for Traefik.
  • The SSH port (22 or yours), for administration and emergency access.

The domain

Each app is served on its own subdomain (radarr.mathod.fr), never by IP and port: container ports stay on the internal dotbox network. So you need a domain name of your own.

DNS

Dot Box requests a wildcard certificate *.mathod.fr from Let's Encrypt (or ZeroSSL, set in dotbox.yml) through the DNS-01 challenge. It needs an API token from your DNS provider, limited to the domain's zone.

ProviderWhat you need
Cloudflarean API token with the "Zone DNS: Edit" permission on the zone
OVHapplication key, application secret and consumer key
Scalewayan API key
Gandia personal access token
Otherany provider Traefik supports, or records created by hand

With a supported provider, Dot Box also creates the wildcard's A and AAAA records pointing to the server. Otherwise, create *.mathod.fr by hand before running dotbox init.

Optional

  • Off-server storage for backups: an rclone remote, a NAS over SFTP or an S3 bucket.
  • Sources for Prowlarr: not needed to install, only to download.
  • A Plex account, only if you install Plex. Jellyfin needs no outside account.
