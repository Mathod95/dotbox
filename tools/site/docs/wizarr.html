Ce que fait Wizarr

  • Tu crées une invitation: un lien, valable une fois ou un temps donné, vers certaines bibliothèques.
  • La personne invitée ouvre le lien, choisit son nom et son mot de passe: Wizarr crée son compte sur Jellyfin ou Plex.
  • Il lui montre ensuite un guide: quelle app installer sur sa TV ou son téléphone, comment se connecter, comment demander un film dans Seerr.

L'installation, pas à pas

Tant qu'aucun compte admin n'existe, n'importe qui pourrait en créer un et prendre la main sur Wizarr. Il reste donc derrière Authelia jusque-là. Sa base est en SQLite: dotbox demande à Wizarr lui-même si son assistant est fini (tant qu'il ne l'est pas, toutes ses pages renvoient vers /setup).

1. Installer

$ dotbox install wizarr
✓ [1/1] Wizarr        v2026.10.1, two_factor until set up

  wizarr        https://wizarr.example.com  two_factor for now

  → Open https://wizarr.example.com and finish its first-run setup (Authelia asks you to log in first).
    Then run dotbox install wizarr again: Authelia steps aside (public).

2. Faire l'assistant

  • Ouvre https://wizarr.example.com, connecte-toi à Authelia, puis crée le compte admin de Wizarr, avec un mot de passe long.
  • Ajoute ton serveur média. Pour Jellyfin: l'adresse http://jellyfin:8096 (par le réseau dotbox) et une clé d'API, créée dans Jellyfin (Tableau de bord, Clés API).

3. Ouvrir Wizarr

$ dotbox install wizarr
✓ [1/1] Wizarr        v2026.10.1, public

  wizarr        https://wizarr.example.com  public

Authelia se retire: un lien d'invitation s'ouvre pour n'importe qui, sans compte. AppSec reste devant.

Ce qui le protège

  • Pendant l'assistant: Authelia, avec la double authentification.
  • Ensuite: le compte admin de Wizarr pour l'administration, et AppSec, qui bloque les attaques connues (Security).
  • CrowdSec ne lit pas ses logs: Wizarr y écrit l'IP d'un échec de connexion à partir d'un en-tête que n'importe quel client peut envoyer. Lu par CrowdSec, ce log permettrait de faire bannir l'IP de quelqu'un d'autre.

What Wizarr does

  • You create an invitation: a link, valid once or for a given time, to some libraries.
  • The invited person opens the link, picks a name and a password: Wizarr creates their account on Jellyfin or Plex.
  • It then shows them a guide: which app to install on their TV or phone, how to log in, how to request a movie in Seerr.

The install, step by step

Until an admin account exists, anyone could create one and take over Wizarr. So it stays behind Authelia until then. Its database is SQLite: dotbox asks Wizarr itself whether its setup is done (until it is, all its pages redirect to /setup).

1. Install

$ dotbox install wizarr
✓ [1/1] Wizarr        v2026.10.1, two_factor until set up

  wizarr        https://wizarr.example.com  two_factor for now

  → Open https://wizarr.example.com and finish its first-run setup (Authelia asks you to log in first).
    Then run dotbox install wizarr again: Authelia steps aside (public).

2. Run the setup

  • Open https://wizarr.example.com, log in to Authelia, then create Wizarr's admin account, with a long password.
  • Add your media server. For Jellyfin: the address http://jellyfin:8096 (over the dotbox network) and an API key, created in Jellyfin (Dashboard, API Keys).

3. Open Wizarr

$ dotbox install wizarr
✓ [1/1] Wizarr        v2026.10.1, public

  wizarr        https://wizarr.example.com  public

Authelia steps aside: an invitation link opens for anyone, without an account. AppSec stays in front.

What protects it

  • During the setup: Authelia, with two-factor authentication.
  • Afterwards: Wizarr's admin account for administration, and AppSec, which blocks known attacks (Security).
  • CrowdSec does not read its logs: Wizarr writes the IP of a failed login from a header any client can send. Read by CrowdSec, that log would let someone get another person's IP banned.
