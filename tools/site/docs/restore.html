Restaurer et migrer●une sauvegarde suffit pour remonter un serveur, ici ou ailleurs.

Restore and migrate●one backup is enough to rebuild a server, here or elsewhere.

Restaurer une app

$ dotbox restore latest --app radarr

Remplace /opt/radarr par sa dernière sauvegarde et relance l'app. Les autres apps ne bougent pas. À la place de latest, une date ou un chemin d'archive précis.

Restaurer tout le serveur

$ dotbox restore latest

Restaure /opt/dotbox, puis chaque app, puis lance sync pour que tout ce qui tourne corresponde à la config restaurée.

Migrer vers un nouveau serveur

  1. Sur l'ancien serveur, une sauvegarde vers une destination que le nouveau peut joindre: dotbox backup --to rclone:b2:dotbox-backups.
  2. Sur le nouveau, télécharge Dot Box (Installation, étape 1). Pas besoin de lancer init.
  3. Restaure: dotbox restore rclone:b2:dotbox-backups --key backup.key. Dot Box relit la config de la sauvegarde, refait l'installation du socle avec elle (Docker, Traefik, Authelia, certificat), puis restaure toutes les apps.
  4. Le DNS: avec un fournisseur pris en charge, Dot Box repointe *.mathod.fr vers la nouvelle IP. Sinon, change l'enregistrement à la main.
  5. Les médias: copie /data avec rsync s'ils doivent suivre.

Les apps ajoutées avec dotbox add et celles du Sandbox sont dans la sauvegarde: elles reviennent avec le reste, rien à réinstaller à la main.

Changer de domaine

$ dotbox config set domain nouveau.fr
$ dotbox sync

Tout est généré à partir de dotbox.yml: sync refait le certificat, les labels Traefik et la config d'Authelia. Il ne reste à corriger que les adresses que tu as saisies toi-même dans les réglages des apps (notifications, webhooks).

Restore an app

$ dotbox restore latest --app radarr

Replaces /opt/radarr with its latest backup and restarts the app. Other apps are not touched. Instead of latest, a date or a specific archive path.

Restore the whole server

$ dotbox restore latest

Restores /opt/dotbox, then every app, then runs sync so everything running matches the restored config.

Migrate to a new server

  1. On the old server, back up to a destination the new one can reach: dotbox backup --to rclone:b2:dotbox-backups.
  2. On the new one, download Dot Box (Installation, step 1). No need to run init.
  3. Restore: dotbox restore rclone:b2:dotbox-backups --key backup.key. Dot Box reads the config from the backup, reinstalls the base with it (Docker, Traefik, Authelia, certificate), then restores every app.
  4. DNS: with a supported provider, Dot Box points *.mathod.fr to the new IP. Otherwise, change the record by hand.
  5. Media: copy /data with rsync if it should come along.

Apps added with dotbox add and those from the Sandbox are in the backup: they come back with everything else, nothing to reinstall by hand.

Change the domain

$ dotbox config set domain new.fr
$ dotbox sync

Everything is generated from dotbox.yml: sync redoes the certificate, the Traefik labels and the Authelia config. Only the addresses you typed yourself in app settings (notifications, webhooks) are left to fix.
