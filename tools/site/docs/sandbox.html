Les trois utilisent le même format de manifest: une app du Sandbox ou une des tiennes suit les mêmes chemins, le même réseau et les mêmes règles d'accès que le reste, et elle est sauvegardée de la même façon.

Ajouter ta propre app

$ dotbox add ./docker-compose.yml --name immich
$ dotbox install immich

add lit le fichier compose du projet et en fait un manifest: sous-domaine, niveau d'accès, volumes rangés dans /opt/immich et /data, réseau dotbox, version d'image fixée. Relis /opt/dotbox/apps/immich.yml avant d'installer.

Proposer une app au Sandbox

Une app qui marche chez toi peut rejoindre le Sandbox par une pull request sur Mathod95/dotbox-sandbox. Son manifest doit:

  • utiliser une image publique avec une version fixe, jamais latest;
  • ranger sa config dans /opt/<app> et ses données sous /data;
  • déclarer son niveau d'accès (two_factor, one_factor, app ou public);
  • avoir un pictogramme 7 × 7 pour le catalogue.

Apps retirées

Une app peut quitter le Sandbox, par exemple quand le projet est abandonné. Elle continue de tourner chez toi: son compose.yml reste dans /opt/<app>. dotbox status la marque « hors catalogue », et dotbox remove la retire quand tu veux.

Add your own app

$ dotbox add ./docker-compose.yml --name immich
$ dotbox install immich

add reads the project's compose file and turns it into a manifest: subdomain, access level, volumes placed in /opt/immich and /data, dotbox network, pinned image version. Review /opt/dotbox/apps/immich.yml before installing.

Submit an app to the Sandbox

An app that works for you can join the Sandbox through a pull request on Mathod95/dotbox-sandbox. Its manifest must:

  • use a public image with a pinned version, never latest;
  • keep its config in /opt/<app> and its data under /data;
  • declare its access level (two_factor, one_factor, app or public);
  • have a 7 × 7 pictogram for the catalog.

Retired apps

An app can leave the Sandbox, for example when its project is abandoned. It keeps running on your server: its compose.yml stays in /opt/<app>. dotbox status marks it "off catalog", and dotbox remove removes it whenever you want.
