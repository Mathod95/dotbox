Sécurité●ce que Dot Box met en place pour protéger ton serveur, couche par couche.

Security●what Dot Box sets up to protect your server, layer by layer.

Un serveur exposé sur Internet est attaqué en permanence: sur un serveur neuf, des milliers d'essais de mots de passe SSH arrivent chaque jour. Dot Box ne compte pas sur une seule protection, il les empile. Une requête doit les passer toutes avant d'atteindre une app.

Les ports ouverts

  • 80 et 443, publiés par Traefik. Le port 80 ne sert qu'à obtenir les certificats et à rediriger vers HTTPS.
  • 22, ton SSH, que Dot Box ne touche pas.
  • Les ports qui ne sont pas du web et qu'une app déclare, comme celui des pairs de qBittorrent. Jamais un port web: tout le web passe par Traefik.

L'API de CrowdSec n'écoute que sur 127.0.0.1, jamais sur Internet. Dot Box n'installe ni n'active aucun pare-feu du système (ufw, firewalld), et ne gère pas celui qui serait déjà actif.

Traefik

  • HTTPS partout: un certificat Let's Encrypt par sous-domaine, et le HTTP redirigé vers HTTPS.
  • Seules les apps installées par Dot Box sont routées: un container n'est exposé que s'il le demande (exposedByDefault: false).
  • Traefik ne touche pas au socket Docker. Un petit proxy le lit pour lui, en lecture seule: il ne peut que lister les containers, jamais en créer ni en modifier, et il n'est joignable que par Traefik.
  • Les en-têtes qui imitent ceux d'Authelia (X_Auth_User pour X-Auth-User) sont supprimés, pour qu'un visiteur ne puisse pas se faire passer pour un utilisateur connecté.
  • Le tableau de bord de Traefik n'est joignable que derrière Authelia, en double authentification.
  • Pas de télémétrie: Traefik ne vérifie pas ses mises à jour et n'envoie pas de statistiques.
  • Un log d'accès, lu par CrowdSec.

Authelia

  • Tout est refusé par défaut. Seules les règles écrites par Dot Box ouvrent un accès.
  • Pour les apps derrière Authelia, la double authentification: ton mot de passe, puis un code à 6 chiffres ou une passkey.
  • Trois mots de passe ratés en deux minutes bloquent le compte cinq minutes, même avec le bon mot de passe ensuite.
  • Fermé en cas de doute: si Authelia ne répond pas, Traefik refuse les apps qu'il protège au lieu de les ouvrir.
  • Ton mot de passe est stocké haché (argon2id), et ses secrets sont dans /opt/dotbox/secrets, lisibles par root seul.

Les niveaux d'accès, app par app, sont décrits dans Accessing Apps.

Les apps

  • Aucune ne publie de port web: elles ne sont joignables que par Traefik, derrière Authelia selon leur niveau.
  • Elles tournent avec ton utilisateur, jamais en root, et sans pouvoir gagner de privilèges (no-new-privileges).
  • Leur image est l'officielle du projet, sinon celle de linuxserver, toujours à une version fixée: une mise à jour est un changement voulu et testé (d'où viennent les images).
  • Les réglages que Dot Box ajoute renforcent l'app quand c'est utile: par exemple, Radarr et Sonarr ne répondent qu'à leur propre adresse, et leur fichier de configuration, qui contient leur clé d'API, n'est lisible que par ton utilisateur.

CrowdSec

  • Il lit les connexions SSH (dans le journal du système) et le log d'accès de Traefik, et y repère les attaques: essais de mots de passe, scans de pages, failles connues.
  • Une IP qui attaque est bannie pour tout le serveur: elle n'atteint plus ni SSH, ni Traefik, ni aucune app. Le blocage se fait dans le noyau, par une liste d'IP bannies, avec iptables-nft: la commande iptables de Debian, qui écrit ses règles dans nftables. Docker s'en sert déjà pour ses propres règles. Le bouncer ajoute ses règles dans deux chaînes: INPUT (SSH) et DOCKER-USER (Traefik et les ports des apps). Rien d'autre n'est bloqué.
  • Il partage les attaques qu'il voit avec la communauté CrowdSec, et reçoit en échange une liste d'IP déjà repérées ailleurs, bloquées d'avance. Ce qui part: le type d'attaque, l'heure et l'IP de l'attaquant.
  • Dot Box installe l'image officielle de CrowdSec, et le binaire officiel du bouncer, son empreinte vérifiée.

Les connexions des apps sans Authelia

Une app sans Authelia devant a sa propre page de connexion, ouverte à Internet. Jellyfin, par exemple, ne bloque pas un compte après des mots de passe ratés. Pour ces apps, CrowdSec lit aussi leurs logs et bannit une IP qui essaie des mots de passe, pour tout le serveur.

  • Le manifest de l'app dit quelle collection du hub de CrowdSec installer, par exemple LePresidente/jellyfin pour Jellyfin. dotbox install l'installe, dotbox remove arrête la lecture.
  • CrowdSec lit les logs du container par l'API Docker, à travers son propre socket proxy, en lecture seule. Traefik n'a pas accès à ces logs.
  • Dot Box teste la configuration de CrowdSec avant de la lui faire relire: un fichier qui l'empêcherait de démarrer n'est jamais gardé.

AppSec

Le pare-feu web de CrowdSec. Il examine chaque requête avant qu'elle n'atteigne l'app, et bloque dès la première une tentative d'exploiter une faille connue, même venant d'une IP jamais vue: une règle par faille connue (le virtual patching), et des règles pour les attaques génériques. Dot Box l'active sur les apps sans Authelia devant (Jellyfin, Plex, Seerr, Vaultwarden, Wizarr), celles qu'Internet peut atteindre directement, et sur la page de connexion d'Authelia. Les autres sont déjà protégées par Authelia.

  • Traefik soumet chaque requête à CrowdSec par le plugin que la doc de CrowdSec indique pour Traefik. Dot Box en garde une copie vérifiée sur le serveur: Traefik ne télécharge rien au démarrage.
  • Une requête bloquée reçoit une erreur 403. Plusieurs attaques différentes en moins d'une minute font bannir l'IP pour tout le serveur, comme le fait CrowdSec.
  • Si CrowdSec ne répond pas, ces requêtes sont refusées plutôt que laissées sans contrôle. C'est le cas pendant une trentaine de secondes quand CrowdSec redémarre.

SSH (prévu)

Dot Box ne modifie jamais la configuration de SSH de lui-même: c'est ton accès au serveur. Une option, que tu choisiras d'appliquer, le durcira (son contenu est encore à définir). En attendant, CrowdSec bannira les IP qui essaient des mots de passe.

Ce que Dot Box ne fait pas

  • Il n'installe ni ne gère de pare-feu du système.
  • Il ne change pas la configuration de SSH sans ton accord.
  • Il ne met pas à jour le système et ne redémarre pas le serveur: dotbox doctor te signale ce qui attend.

A server exposed to the Internet is attacked all the time: on a brand new server, thousands of SSH password attempts arrive every day. Dot Box does not rely on a single protection, it stacks them. A request has to get through all of them before reaching an app.

Open ports

  • 80 and 443, published by Traefik. Port 80 is only used to get certificates and to redirect to HTTPS.
  • 22, your SSH, which Dot Box does not touch.
  • Non-web ports an app declares, such as qBittorrent's peer port. Never a web port: all web traffic goes through Traefik.

CrowdSec's API only listens on 127.0.0.1, never on the Internet. Dot Box neither installs nor enables any system firewall (ufw, firewalld), and does not manage one that would already be active.

Traefik

  • HTTPS everywhere: a Let's Encrypt certificate per subdomain, and HTTP redirected to HTTPS.
  • Only the apps installed by Dot Box are routed: a container is exposed only if it asks to be (exposedByDefault: false).
  • Traefik does not touch the Docker socket. A small proxy reads it on its behalf, read-only: it can only list containers, never create or change them, and only Traefik can reach it.
  • Headers that mimic Authelia's (X_Auth_User for X-Auth-User) are removed, so that a visitor cannot pose as a logged-in user.
  • Traefik's dashboard is only reachable behind Authelia, with two-factor authentication.
  • No telemetry: Traefik does not check for updates and sends no statistics.
  • An access log, read by CrowdSec.

Authelia

  • Everything is denied by default. Only the rules written by Dot Box open access.
  • For apps behind Authelia, two-factor authentication: your password, then a 6-digit code or a passkey.
  • Three failed passwords in two minutes lock the account for five minutes, even with the right password afterwards.
  • Closed when in doubt: if Authelia does not answer, Traefik refuses the apps it protects instead of opening them.
  • Your password is stored hashed (argon2id), and its secrets are in /opt/dotbox/secrets, readable by root only.

Access levels, app by app, are described in Accessing Apps.

Apps

  • None publishes a web port: they are only reachable through Traefik, behind Authelia according to their level.
  • They run as your user, never as root, and cannot gain privileges (no-new-privileges).
  • Their image is the project's official one, otherwise linuxserver's, always at a fixed version: an update is a deliberate, tested change (where images come from).
  • The settings Dot Box adds harden the app when useful: for example, Radarr and Sonarr only answer to their own address, and their configuration file, which holds their API key, is readable by your user only.

CrowdSec

  • It reads SSH connections (in the system journal) and Traefik's access log, and spots attacks there: password attempts, page scans, known vulnerabilities.
  • An attacking IP is banned for the whole server: it no longer reaches SSH, Traefik or any app. Blocking happens in the kernel, through a list of banned IPs, with iptables-nft: the iptables command of Debian, which writes its rules into nftables. Docker already uses it for its own rules. The bouncer adds its rules to two chains: INPUT (SSH) and DOCKER-USER (Traefik and the apps' ports). Nothing else is blocked.
  • It shares the attacks it sees with the CrowdSec community, and receives in return a list of IPs already spotted elsewhere, blocked in advance. What is sent: the type of attack, the time and the attacker's IP.
  • Dot Box installs CrowdSec's official image, and the bouncer's official binary, its checksum verified.

Logins of apps without Authelia

An app without Authelia in front has its own login page, open to the Internet. Jellyfin, for example, does not lock an account after failed passwords. For these apps, CrowdSec also reads their logs and bans an IP that guesses passwords, for the whole server.

  • The app's manifest says which CrowdSec hub collection to install, for example LePresidente/jellyfin for Jellyfin. dotbox install installs it, dotbox remove stops the reading.
  • CrowdSec reads the container's logs through the Docker API, via its own socket proxy, read-only. Traefik has no access to these logs.
  • Dot Box tests CrowdSec's configuration before making it reload: a file that would keep it from starting is never kept.

AppSec

CrowdSec's web application firewall. It inspects each request before it reaches the app, and blocks an attempt to exploit a known vulnerability from the very first one, even from an IP never seen before: one rule per known vulnerability (virtual patching), and rules for generic attacks. Dot Box enables it on apps without Authelia in front (Jellyfin, Plex, Seerr, Vaultwarden, Wizarr), the ones the Internet can reach directly, and on Authelia's login page. The others are already protected by Authelia.

  • Traefik submits each request to CrowdSec through the plugin CrowdSec's documentation points to for Traefik. Dot Box keeps a verified copy of it on the server: Traefik downloads nothing at startup.
  • A blocked request gets a 403 error. Several different attacks within a minute get the IP banned for the whole server, as CrowdSec does.
  • If CrowdSec does not answer, these requests are refused rather than let through unchecked. That is the case for about thirty seconds when CrowdSec restarts.

SSH (planned)

Dot Box never changes the SSH configuration on its own: it is your access to the server. An option, which you will choose to apply, will harden it (its content is still to be defined). Meanwhile, CrowdSec will ban the IPs that try passwords.

Dotbox never changes the SSH configuration on its own: it is your access to the server. You turn the hardening on yourself, once your SSH key works: keys only, no root login, 3 attempts per connection, a forgotten session closed after 10 minutes, no agent forwarding. A safety net puts SSH back as it was if you do not confirm from a new connection within 5 minutes (see Post-installation). Meanwhile, CrowdSec bans the IPs that try passwords.

What Dot Box does not do

  • It neither installs nor manages a system firewall.
  • It does not change the SSH configuration without your agreement.
  • It does not update the system or reboot the server: dotbox doctor tells you what is pending.
