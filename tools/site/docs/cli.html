    The db shortcut

    dotbox init also installs db, a shorter name for the same command: db status, db install radarr, sudo db init. It is a link to dotbox in /usr/local/bin, so it works with sudo and in scripts, and dotbox upgrade keeps it. The script of dotbox completion declares both names. The pages of this site always write dotbox.

    If a db command already exists on the server, Dot Box leaves it alone: the Service line of init says db taken, no shortcut, and only dotbox is there.
