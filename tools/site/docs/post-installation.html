Post-installation●what Dot Box checks for you, and what is left to do.

Lancer dotbox doctor

Avant tout, doctor vérifie le serveur et liste ce qui reste à faire. Chaque point ci-dessous correspond à une de ses lignes.

$ dotbox doctor
  ok    docker 28.2, network dotbox
  ok    certificate *.mathod.fr valid for 89 days
  warn  ssh accepts passwords
  warn  ssh allows root login
  warn  backup only local (/backups)
  ok    /data 12% used

Sécuriser SSH

Dot Box ne modifie jamais la configuration SSH: une erreur pourrait te fermer la porte du serveur. doctor signale ce qui manque, à toi de l'appliquer dans /etc/ssh/sshd_config:

  • Clés seulement: PasswordAuthentication no.
  • Pas de root: PermitRootLogin no.
  • Garde une session ouverte pendant que tu testes la nouvelle configuration dans une deuxième.

Sortir les sauvegardes du serveur

La sauvegarde quotidienne est active dès init, mais en local: un disque qui lâche l'emporte avec lui. Ajoute une destination distante, voir Backup.

Créer les comptes

$ dotbox user add lea --group family

Les groupes décident des apps accessibles: family voit Jellyfin et Seerr, admins voit tout. Le compte reçoit un lien d'invitation valable 48 heures pour choisir son mot de passe et sa double authentification.

Surveiller l'espace disque

Les téléchargements terminés mais pas encore importés restent dans /data/torrents, tout comme ceux que Radarr ou Sonarr n'ont pas reconnus. doctor prévient à 85 % d'occupation, et Uptime Kuma peut envoyer l'alerte sur Discord ou par e-mail.

Garder un accès de secours

Si Authelia ou l'interface ne répondent plus: en SSH, dotbox --local parle directement au moteur. Note la commande quelque part avant d'en avoir besoin.

Run dotbox doctor

First, doctor checks the server and lists what is left to do. Each point below matches one of its lines.

$ dotbox doctor
  ok    docker 28.2, network dotbox
  ok    certificate *.mathod.fr valid for 89 days
  warn  ssh accepts passwords
  warn  ssh allows root login
  warn  backup only local (/backups)
  ok    /data 12% used

Secure SSH

Dot Box never changes the SSH configuration: a mistake could lock you out of the server. doctor reports what is missing, and you apply it in /etc/ssh/sshd_config:

  • Keys only: PasswordAuthentication no.
  • No root: PermitRootLogin no.
  • Keep a session open while you test the new configuration in a second one.

Move backups off the server

The daily backup is on from init, but local: a failing disk takes it with it. Add a remote destination, see Backup.

Create accounts

$ dotbox user add lea --group family

Groups decide which apps are reachable: family sees Jellyfin and Seerr, admins sees everything. The account gets an invite link, valid for 48 hours, to choose its password and two-factor method.

Watch disk space

Finished downloads that are not imported yet stay in /data/torrents, as do the ones Radarr or Sonarr could not recognize. doctor warns at 85% usage, and Uptime Kuma can send the alert to Discord or by email.

Keep emergency access

If Authelia or the interface stop responding: over SSH, dotbox --local talks to the engine directly. Write the command down before you need it.
