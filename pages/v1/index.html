      Dot Box

      Conception (v0.0.1)

      Dot Box installe et câble des apps auto-hébergées sur un serveur Debian ou Ubuntu. Chaque app est un petit manifest YAML; un moteur Rust le transforme en fichier Docker Compose lisible, avec à chaque fois les mêmes chemins, le même réseau, les certificats et le SSO. Pas de catalogue à attendre: si un projet fournit un compose, il peut devenir une app.

      Comment ça marche

      Le manifestYAML

      Ce que tu veux: image, volumes, sous-domaine, SSO, et comment l'app se branche aux autres.

      name: radarr
image: lscr.io/linuxserver/radarr
subdomain: radarr
sso: true
volumes:
  - /opt/radarr:/config
  - /data:/data
wiring:
  root_folder: /data/media/movies
  download_clients:
    - app: qbittorrent
      category: radarr

      Le moteurRust

      Applique les conventions, écrit les configs avant le premier démarrage, puis câble les apps entre elles par leurs API.

      # conventions
réseau      dotbox
config      /opt/<app>
médias      /data  # hardlinks
proxy       traefik + DNS-01
sso         authelia

# après le démarrage
POST /api/v3/rootfolder
POST /api/v3/downloadclient

      Le résultatCompose

      Un fichier compose normal, que tu peux lire. Tes ajustements vivent dans l'override, que Dot Box ne touche jamais.

      /opt/radarr/
├── compose.yml           # généré
├── compose.override.yml  # à toi
└── config/

# sans Dot Box, ça tourne quand même
$ docker compose up -d

      Fonctionnalités

      Catalogue ouvert

      Colle le docker-compose.yml d'un projet: Dot Box en fait un manifest avec les chemins, les labels et le SSO standards.

      Une seule arborescence

      Config dans /opt/<app>, médias dans un seul montage /data. Téléchargements et bibliothèques partagent un filesystem: les imports sont des hardlinks, pas des copies.

      Sous-domaines et certificats

      Traefik route chaque app vers son sous-domaine. Let's Encrypt en DNS-01 fournit un seul certificat wildcard pour toutes.

      SSO par défaut

      Authelia protège chaque app sauf indication contraire du manifest. L'interface de Dot Box n'est jamais joignable sans lui.

      Câblage automatique

      Installe Radarr après qBittorrent et il est déjà branché: client de téléchargement, catégorie, dossier racine. Prowlarr et Jellyfin suivent la même règle.

      Compose lisible

      Chaque app est un fichier compose sur le disque. Si Dot Box disparaît demain, tes apps tournent toujours et restent gérables à la main.

      Réconciliation

      L'état voulu d'un côté, les containers qui tournent de l'autre. Dot Box montre l'écart et le corrige, comme ArgoCD pour un cluster.

      Sauvegarde et migration

      Tout ce qui compte vit dans /opt et les manifests. Restaure les deux sur un serveur neuf et lance une commande.

      Apps

      Le catalogue de départ. Traefik et Authelia sont installés par dotbox init.

      CLI et web, une seule API

      Le même moteur, du terminal ou du navigateur

      L'interface web et la commande dotbox appellent toutes les deux l'API du serveur. Jobs, logs et historique sont partagés, et un seul endroit parle à Docker.

      • Les logs d'installation défilent en direct, dans le terminal comme dans le navigateur.
      • Docker est joint via un socket proxy, jamais le socket brut.
      • Un mode --local marche même si le serveur web est tombé.
